## Limits

- `RecoveryStatus::InProgress`, `RecoveryReport.abandoned` and
  `pending_recovery` were not produced live; they pass Bark's values through.
- The new `CpfpParams` fields reach only callback onchain wallets, which no
  live test drives through an RBF.
- Bark's Nostr Wallet Connect (`nwc` feature) is not exposed.
